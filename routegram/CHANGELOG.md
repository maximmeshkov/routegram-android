# Routegram — патчноты

Версия форка живёт в `routegram/version.properties` (бампать ТОЛЬКО там).
Базируется на Telegram for Android (точная база — в подвале настроек).
Семантика: `0.МИНОР.ПАТЧ`, пока < 1.0 — стадия становления.

---

## 0.1.3 — заглушки UI, билингва, супервайзер по таймингу Telegram

Всё, что уже реализовано и разошлось с master (0.1.1).
(0.1.2 — промежуточный standalone-APK без отдельного коммита, целиком входит сюда.)

### Заглушки UI (ловушки закрыты)
- **Прокси-меню заблокировано** диалогом «клиент использует свою систему обхода»
  (только «Назад»). Перехват и экрана (`ProxyListActivity`), и **deep-link `tg://proxy`**
  (`showProxyAlert`) — иначе юзер, случайно нажав на прокси-ссылку, добавил бы внешний
  прокси и не смог бы его убрать (ловушка).
- **Звонки** (голос/видео/войс-чаты) заблокированы диалогом со ссылкой на FAQ
  (issue #389) — MTProto/ws-proxy архитектурно не умеет звонки. Блок всегда.
- **Билингва RU/EN** для диалогов — по текущей локали (`routegramIsRu`).

### Супервайзер
- Реагирует **по состоянию соединения клиента**, тайминг берёт из самого Telegram
  (`ProxyRotationController.ROTATION_TIMEOUTS`, с учётом настройки пользователя), а не из
  выдуманной/девайс-зависимой константы.
- **Гасит кратковременный дребезг tgnet** (Connected → ConnectingToProxy → Connected за
  ~200 мс): ждём T и перепроверяем — если вернулись, движок НЕ трогаем. Убрало ложные
  «подключение к прокси на пустом месте» и лишние рестарты движка, которые супервайзер
  раньше сам же и создавал.
- Быстрый подъём прокси на старте (самый первый раз — без задержки).
- DIAG-логи сделаны человекочитаемыми (имена состояний).

## 0.1.1 — логика включения/выключения tgwsproxy

- `apply(null)` теперь реально выключает прокси (`setProxySettings(false, …)`), а не
  был пустышкой.
- Проба «есть ли нормальный интернет» (`ForeignProbe`); при отсутствии инета прокси
  выключается, чтобы клиент честно показывал «нет сети», а не «подключение к прокси».
- Супервайзер по состоянию соединения вместо циклического опроса.

## 0.1.0 — MVP

- Встроенный движок tg-ws-proxy (amurcanov) как нативная либа (`:routegram:libtgwsproxy`,
  сборка .so через cargo-ndk), вызов по JNA.
- Авто-инициализация без правки `ApplicationLoader` — через `ContentProvider`.
- Модульная архитектура: `:routegram:core` (интерфейсы), `:routegram:glue` (привязка к
  клиенту), `:routegram:libtgwsproxy` (обёртка движка) — чтобы легко бампать и движок, и базу.
